# Wellspring Community Center website

Static website for Wellspring Community Center (Milford, CT), hosted on GitHub Pages.

- Pages: `index.html`, `about.html`, `programs.html`, `contact.html`, `policies.html`, `404.html`
- Styles: `styles.css` · Script: `main.js` · Photos: `images/`
- Every push to `main` publishes automatically (see `.github/workflows/pages.yml`).

**Donate links** point to the Zeffy donation form: https://www.zeffy.com/en-US/donation-form/building-humanity-trough-equity-dialog-and-purpose
